# Расписание 214Р

Минималистичное расписание для группы 214Р. Приложение позволяет переключать день, подгруппу и учебную неделю, а неделю можно менять свайпом на мобильных устройствах.

## Разработка

```bash
npm ci
npm run dev
```

Проверки перед коммитом:

```bash
npm run lint
npm run build
```

## Структура

- `app/` — Next.js entry points и глобальные стили.
- `components/` — интерактивный экран расписания и карточки занятий.
- `lib/schedule.ts` — типы и чистые функции работы с данными расписания.
- `app/table.json` — исходные данные расписания.
