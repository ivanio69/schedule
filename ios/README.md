# Schedule 214Р — iOS companion + WidgetKit

Это минимальная нативная оболочка для системного iOS-виджета. Основное приложение остаётся Next.js/PWA.

## Preview API

Пока PR #81 не смержен, companion и WidgetKit направлены на preview alias ветки:

`https://schedule-git-feature-ios-widget-ivanio.vercel.app`

После merge этот адрес нужно вернуть на production URL.

## Что уже есть

- приложение сразу открывает существующий веб-интерфейс внутри WKWebView;
- авторизация и настройки выполняются прямо внутри iOS-приложения;
- сопряжение с текущим веб-профилем через одноразовый deep link, который WKWebView перехватывает внутри приложения;
- отдельный read-only widget token вместо personId;
- Small и Medium Home Screen widgets;
- Lock Screen варианты accessoryRectangular и accessoryInline;
- timeline на начало и конец событий без сетевого запроса каждую минуту;
- кэш последней успешной сводки в App Group;
- переход из companion-приложения в основное расписание.

## Запуск

1. Установи Xcode 26+ и XcodeGen.
2. В терминале:

   ```bash
   cd ios
   xcodegen generate
   open Schedule214.xcodeproj
   ```

3. В Xcode выбери свою Development Team для targets `Schedule214` и `ScheduleWidget`.
4. Если Apple Developer Portal не позволяет App Group `group.com.schedule214.shared`, замени его одинаково в:
   - `Schedule214/Schedule214.entitlements`
   - `ScheduleWidget/ScheduleWidget.entitlements`
   - `Shared/WidgetEnvironment.swift`
5. Запусти приложение на iPhone — оно сразу откроет веб-интерфейс на странице настроек.
6. Войди в профиль прямо внутри приложения и нажми **Приложение → iOS-виджет → Подключить iPhone**.
7. WKWebView перехватит deep link и передаст одноразовый код нативной части без перехода в Safari.
8. После успешного подключения добавь виджет «214Р · Мой день» через системную галерею виджетов.

## Live Activity во время пар — новая реализация

Код разделён на `ClassActivityPlan` (отбор пар), `ClassActivityController`
(жизненный цикл), `ClassActivityAttributes` (данные) и `ClassLiveActivity` (UI).
Старая реализация удалена. Репетиции и индивидуальные занятия в эту Activity не входят.

- Экран блокировки: название, преподаватель/аудитория, обратный отсчёт, прогресс и время начала/конца.
- Dynamic Island: compact, minimal и expanded. Нажатие открывает расписание внутри приложения.
- Таймер и прогресс отрисовываются системой даже при приостановленном приложении.
- На iOS 17–25 текущая пара запускается при открытии приложения; при открытом приложении границы проверяются каждые 5 секунд.
- На iOS 26+ дополнительно планируются три ближайшие пары из загруженного расписания на сегодня/завтра. Система уведомляет о запуске — это обязательное условие scheduled ActivityKit.
- Отменённые пары пропускаются. Перенесённые используют новое время из feed.
- При синхронизации изменяются название/аудитория; перенос начала запланированной Activity пересоздаёт запрос.
- Расписание интерпретируется в `Europe/Minsk`, независимо от часового пояса телефона.
- Сеть опрашивается только при открытом приложении, раз в минуту и при возвращении на экран. Без сети ранее запланированные Activity не отменяются.
- `NSSupportsLiveActivities` присутствует в обоих plist; исправлен конфликт XML. Новые файлы подключены в сохранённый Xcode-проект и XcodeGen.

### Ограничения системы

Без APNs приложение не может гарантировать фоновое завершение карточки или получить
изменение расписания после закрытия. В конце пары `staleDate` переводит представление
в «Пара завершена» (момент перерисовки определяет iOS), таймер останавливается на нуле.
При следующем открытии/проверке Activity завершается и удаляется. До этого карточка
может оставаться на экране блокировки в пределах системного лимита ActivityKit.
Это не фоновый таймер JavaScript/Swift и не обещание бесконечной автоматической очереди:
для пополнения трёх запланированных пар нужно снова открыть приложение.

Сборка требует Xcode 26+; минимальная версия приложения остаётся iOS 17.
APNs и платная push-capability не используются.

### Проверка

Workflow `iOS` собирает сохранённый проект и embedded extension на macOS,
а также запускает Swift-тесты отбора событий (границы, отмены, переносы,
невалидные даты, дубликаты, разные дни/профили и другой часовой пояс устройства).

На iPhone проверь: подключить профиль во время пары → заблокировать экран →
раскрыть Dynamic Island → нажать карточку → дождаться конца пары. На iOS 26
проверь также запуск заранее запланированной пары после закрытия приложения.
Системное отображение и точность пробуждения требуют проверки на устройстве.
